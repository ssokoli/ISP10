# ISP10 · Aula de español B2

El sitio está preparado para 12 unidades. Unidad 1 se conserva sin cambios de contenido.

## Para publicar una unidad nueva

Reemplaza **solo** `units/unit02.js` (o el número correspondiente) con el material de la unidad y súbelo al repositorio. No cambies `index.html` ni `assets/app.js`. Las rutas usan `?unit=2#inicio`. Los resultados quedan separados por unidad en el navegador. Las rutas antiguas de Unidad 1 se mantienen.

Consulta `units/UNIT_TEMPLATE.js.txt` para preparar una nueva unidad, y `units/unit01.js` para un ejemplo completo.
